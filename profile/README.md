## What we do

We exist to answer one question, fast: **is this idea worth a real team?**

We don't write specs. We don't draw roadmaps. We build the smallest working version of an idea — real data, real models, real users — and put it in front of the studio in days, not quarters.

Most things we build will not ship. That's the point. The work is to learn cheap so Argoman can spend dear in the right places.

## How we cook

| Phase | Days | What happens |
|---|---|---|
| 🥣 **Brief** | Day 0 | A one-paragraph thesis. What it is, who it's for, what we'd learn. |
| 🔪 **Architect** | 1–2 | Stack, data, model. Skeleton stood up — ingestion, retrieval, eval. |
| 🔥 **Build** | 3–8 | Five humans, end-to-end. No mockups, no decks. Something working every day. |
| 🍽️ **Demo & decide** | 9–10 | Live demo. The PoC earns a real team — or gets a clean write-up. |

**Cadence:** ~3 prototypes a month.
